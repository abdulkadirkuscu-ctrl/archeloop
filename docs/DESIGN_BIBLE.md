# Philosophy

ArcheLoop is not a psychology website.

ArcheLoop is not a coaching website.

ArcheLoop is an integrative self-awareness platform.

The design should feel calm, premium, intentional, and timeless.

Every page should communicate clarity rather than stimulation.

Our inspiration is:

- Apple
- Linear
- Notion
- Carl Jung

The goal is to create software that feels thoughtful rather than overwhelming.

---

# Design Principles

Every design decision should support one or more of these principles.

## 1. Simplicity

Remove anything unnecessary.

If something does not improve understanding, remove it.

---

## 2. Consistency

Every page should feel like the same product.

Spacing, typography, colours, buttons and cards should behave consistently.

---

## 3. Hierarchy

The eye should always know where to look first.

Every page follows:

Kicker

↓

Heading

↓

Supporting text

↓

Primary Action

---

## 4. Space

Whitespace is intentional.

Do not fill space simply because it exists.

Premium products breathe.

---

## 5. Colour Has Meaning

Colour is never decorative.

Colour communicates meaning.

Purple

• Shadow
• Understanding
• Pattern Recognition

Yellow

• Interrupt
• Action
• CTA
• Pricing

Green

• Integration
• Growth
• Healthy Direction

---

# Typography

Order of hierarchy

Kicker

↓

Heading

↓

Brand Tagline

↓

Intro Paragraph

↓

Body

↓

CTA

Sentence case is preferred.

Avoid unnecessary capitalisation.

# Components

Reusable UI components

Hero

Section

Container

Button

Card

Pricing Block

Journey Card

Brand Tagline

Section Header

Mission Statement

Divider

Whenever possible create reusable components instead of repeating code.

---

# Buttons

Primary

Used only for the primary action on a page.

Secondary

Used for supporting actions.

Avoid multiple competing primary buttons.

---

# Cards

Cards should feel spacious.

Use consistent:

Padding

Border radius

Shadow

Spacing

Hover behaviour

---

# Pricing

Pricing always uses the campaign colour.

All pricing cards should have:

Consistent spacing

Consistent button heights

Consistent typography

# Mobile First

Every major update must be reviewed on mobile.

Check:

Spacing

Buttons

Navigation

Typography

Overflow

Touch targets

---

# Motion

Motion should feel subtle.

Preferred:

Soft fades

Small lifts

Gentle shadows

Avoid excessive animations.

---

# Future Design Direction

Future improvements should focus on:

Consistency

Typography

Spacing

Micro-interactions

Accessibility

Not additional colours or effects.

---

# Final Principle

Premium is created through consistency, not decoration.

Whenever making a design decision ask:

Does this make ArcheLoop feel calmer?

Does this make ArcheLoop feel clearer?

Does this make ArcheLoop feel more premium?

If not, reconsider the decision.
